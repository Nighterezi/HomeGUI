# Features

## [Home Screen](/features/home-screen)

One list, one click to travel. Rename and delete without touching chat.

## [Home Names](/features/home-names)

Spaces, colour codes and hex. Type the name however you like; lookups ignore the decoration.

## [Teleport Rules](/features/teleport-rules)

Limits, cooldowns, a countdown that can be cancelled by moving, and dimension rules.

## Quiet by default

Nothing about HomeGUI is loud. No permission nodes to wire up, no database to run, no periodic
tasks. Homes are small JSON files inside the world, written when they change and otherwise left
alone.
