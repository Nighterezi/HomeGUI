# Overview

HomeGUI lets a player save a spot and come back to it later. Save with `/sethome`, return with
`/home`, and remove one with `/delhome`.

Running `/home` on its own opens a small screen listing everything you have saved. Click a home
to travel there, rename one in place, or delete it. Players who do not have the mod installed get
the same list printed in chat instead, and every command keeps working for them.

## What you get

- A configurable number of homes per player
- A screen with rename, delete and pagination
- Optional cooldown and a countdown before the teleport, with sound
- Home names with spaces and colour
- English and Vietnamese, chosen from the player's own game language
